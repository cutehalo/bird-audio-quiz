# 🕊️ 听音识鸟 · 中国常见鸟类声音识别挑战赛
> **Bird Audio Quiz** · 探索大自然的交响乐，测试你的自然听音力！

---

## 🌟 项目亮点

- 🎵 **500 种中国鸟类全量野生录音**：收录鸣禽、攀禽、陆禽、猛禽、游禽、涉禽等 69 个科属 500 种中国鸟类 100% 真实野外原声！
- ⚡ **宝可梦大师图鉴 & 羁绊系统**：
  - 每日体力与自然恢复（上限 5 点，每 3 小时恢复 1 点）；
  - 指数经验收集（0★➔1★: 5次, 1★➔2★: 15次, 2★➔3★: 35次）；
  - **同科羁绊共鸣**：同科收集 ≥ 5 种 1★ 激活专属羁绊卡，门槛大幅降至 3 次即可升级；
  - **局内积分兑换道具**：初始 20 积分/次，使用后独立翻倍（20➔40➔80➔160...）；
  - **连击加成阶梯**：每连续答对 5 题积分多翻 1 倍！
- ♾️ **无尽生存挑战**：3 次答错机会，挑战听音极限！
- 🏞️ **生境智能题库**：支持「全部鸟类」、「林鸟题库」、「水鸟题库」自由切换。
- ✂️ **三大智能道具**：排除二错、延至 60 秒、双倍计分。
- 📱 **移动端全响应式设计**：纯图标顶栏防折行、作答后直达「下一题」，无需上下滑动屏幕！

## 🛠️ 技术栈

- **前端架构**：原生 HTML5 + CSS3 + ES6+ JavaScript（零外部依赖，极速秒开）
- **音频引擎**：Web Audio API + HTML5 Audio + Canvas 实时生物声学声波频谱可视化
- **本地存储**：`localStorage` 自动持久化全生涯星级图鉴与体力状态
